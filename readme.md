# Desktop Island

Запуск: `python dyn.py`. Файл `telegram_notifications.py` должен лежать рядом с `dyn.py`.
Для новых функций дополнительные пакеты не нужны: используются установленные PyQt6
и стандартная библиотека Python.

## Управление

- Нажатие на свёрнутый остров раскрывает его. Нажатие на фон раскрытого острова,
  Escape или клик снаружи сворачивает его.
- Колесо мыши переключает плеер, календарь, статистику и Telegram.
  Над текстом сообщения колесо прокручивает сам текст.
- Кнопки плеера: предыдущий трек, воспроизведение/пауза, следующий трек.
- Правая кнопка на фоне острова закрывает приложение.

## Уведомления Telegram

В Telegram Desktop открой **Настройки → Уведомления и звуки**. Включи уведомления
рабочего стола, использование системных уведомлений Windows, показ имени
отправителя и текста сообщения. Названия пунктов могут отличаться между версиями.
Разреши уведомления Telegram также в настройках уведомлений Windows.

После запуска остров отслеживает **новые системные уведомления Telegram** примерно
раз в секунду, в том числе когда окно Telegram свёрнуто. Собственные всплывающие
окна Telegram, уведомления веб-версии и чаты с отключёнными уведомлениями не
отслеживаются. Если Telegram скрывает имя или текст, остров тоже не сможет их показать.
Структура карточки соответствует [системным уведомлениям Telegram Desktop](https://github.com/telegramdesktop/tdesktop/blob/dev/Telegram/SourceFiles/platform/win/notifications_manager_win.cpp).

Свёрнутый остров показывает `TG`, отправителя и число непросмотренных уведомлений.
По нажатию открывается карточка с отправителем, временем и текстом. Автоматического
раскрытия нет. Стрелки внизу листают последние 20 уведомлений, кнопка «К плееру»
возвращает музыку. В группе заголовок может содержать название чата, а имя автора —
первую строку текста, как в уведомлении Telegram.

Просмотр убирает уведомление из счётчика **только в острове**. Он не отмечает
сообщения прочитанными в Telegram и не удаляет их из центра Windows.
История хранится в памяти до закрытия приложения. Старые уведомления, поступившие
до запуска острова, не загружаются.

У обычного запуска `python dyn.py` системный `UserNotificationListener` на проверенной
машине недоступен. Поэтому приложение открывает локальную базу центра уведомлений
`%LOCALAPPDATA%\Microsoft\Windows\Notifications\wpndatabase.db` **только для чтения**
и запрашивает только записи Telegram. Доступ к аккаунту Telegram, токен бота и
интернет-соединение для этой функции не нужны. Это внутренний формат Windows:
обновления ОС могут изменить его. Ошибка доступа отображается в карточке Telegram;
приложение повторяет подключение автоматически и продолжает работу плеера.

## Проверка

`python -m unittest -v test_notifications`

Проверки используют отдельную временную базу и тестовые сообщения. Они проверяют
фильтрацию, повторные уведомления, историю, счётчик, раскрытие по нажатию и попадание
кликов во все кнопки плеера. Рабочая база Windows при тестах не изменяется.

Для проверки реального входящего сообщения перезапусти остров, сверни Telegram
и дождись нового сообщения в чате с включёнными уведомлениями. Сначала проверь,
что оно появилось в центре уведомлений Windows; затем нажми на индикатор `TG`.

## Расход памяти

- Завершённые анимации страниц удаляются, а не накапливаются при переключении.
- Обложка запрашивается только при открытом плеере, один раз для текущего трека.
  В интерфейс передаётся изображение не больше 128 × 128 пикселей. Поток чтения
  обложки закрывается сразу после загрузки, исходные байты не кешируются.
- Для уменьшения памяти при декодировании используется
  [QImageReader.setScaledSize](https://doc.qt.io/qt-6/qimagereader.html#setScaledSize).
  Обложки больше 4 МиБ пропускаются; предел разрешения — 64 млн пикселей для
  форматов с уменьшением при декодировании и 8 млн для остальных. Вместо них
  остаётся значок ноты.
- Статистика ПК обновляется только на её открытой странице. Проверка кликов
  снаружи работает только у раскрытого острова. Telegram продолжает слушать
  уведомления и в свёрнутом состоянии.
- XML уведомлений читается по одному, кеш SQLite ограничен 256 КиБ. В одной
  партии передаётся не больше 20 уведомлений. Нестандартные уведомления свыше
  64 КиБ пропускаются; заголовки ограничены 512, текст — 16384 символами.

Контрольный замер на этом компьютере (МиБ, округление до целого):

| Сценарий | До | После |
| --- | ---: | ---: |
| Простой: собственная память процесса (Private Bytes) | 51 | 51 |
| Простой: резидентная память, включая общие библиотеки (RSS) | 109 | 109 |
| Пиковая RSS после 1000 переключений и чтения JPEG 4096 × 4096 | 193 | 127 |
| Оставшиеся группы анимации после 1000 переключений | 1000 | 0 |

Замер выполнен в отдельных процессах с нативным Qt Windows и невидимым тестовым
окном. В простое фоновые службы работали 2,5 секунды; перед нагрузкой они
останавливались. Это сравнение одинакового сценария, а не гарантированный предел
для любых медиаплееров и размеров обложек. Python и Qt сохраняют базовый расход
памяти даже у маленького свёрнутого окна.
